# Data model

## FeatureContract
- Scenes: `data-scene` 0–5 → ids `top, gecmis, olasilik, anonim, buro, sufle`.
- Tree model (fictional): root branches a .40 / b .45 / c .15; a → kabul .65, kısmi .35; b → kısmi .40, ret .60; c → sulh 1. Moves: expert (a +.12, b −.12), precedent (a.kabul +.12, b.kısmi +.15), settle (c +.20, then renormalise). Outcomes are summed path products.
- Bureau: five fictional lawyers with won cases per type (İş, Kira, Ticaret, Ceza), lost count and approaching deadlines.
