# Data model
## FeatureContract
No table or column changes. Response `SimilarPrecedentOut`: precedent_id, case_number, case_name, case_type, court (str|null), outcome, decision_date (date|null), score (0–100), text_score (0–100), linked_to_case (bool), explanation {shared_terms: list[str] (≤8), shared_statutes: list[str], matching_fields: list[str], passages: list[{case_label, case_text, case_highlights: [{start, end}], precedent_label, precedent_text, precedent_highlights: [{start, end}]}] (≤3)}. Query: limit 1–20, default 5.

Stage 3 response `SimilarPrecedentsResponse {summary, source, items}`. Query adds outcome (repeatable), court, min_score 0–100, explain (bool), precedent_id. `summary`: count, outcomes {outcome: n}, avg_duration_months|null, duration_count, avg_case_value|null, value_count, available_courts, excluded_signals. `source` and `items[].facts` (`FactsOut`): case_type, court, court_type, client_role, case_value, opening_date, decision_date, duration_months, outcome, evidence[], has_expert_report, document_count, statutes[]. Each item = `SimilarPrecedentOut` + case_value, duration_months, score_breakdown [{key, label, points, max_points}], key_differences [{label, case_value, precedent_value}], timeline [{event_date, event_type, title}], facts, ai_explanation {status, text, notice}|null. Still no table or column change.
