# Verification in a disposable bureau

1. Apply Alembic head before starting the updated backend. Load the template from Ayarlar. Existing sample bureaus can load it again to add the ten supplemental decisions.
2. From Davalar open a closed case. Read its recorded outcome and decision note. Use İlgili emsal kararları göster to inspect the file links and category suggestions. As its manager, link another decision and reload. Removing the link should leave the precedent in the bureau archive.
3. Open Olasılık Ağacı in the case tab bar. Select a node or switch to its text view. The case stays selected. On a legacy closed case with no outcome, use Dava sonucunu kaydet to enter the actual decision.
4. On Görevler, drag a card or use its stage menu. Edit notes, responsibility, priority and deadline. Reload and verify its column and fields. Complete it and check that pending counts decrease.
5. Open the four previews in Raporlar. Compare each with the CSV downloaded by the same user on the same underlying data. Empty reports still show the column names.
6. Inspect category rates in Analitik. Each seeded category includes wins and losses. Reimport leaves the stored decisions intact. Preview-confirmed sample removal includes the supplemental cases.
