# FeatureContract

Statik içerik; yeni saklanan veri modeli veya API yok.
- TeamMember.name: beş gerçek isim, her biri bir kez; özgün Türkçe yazım.
- TeamMember.role: kullanıcının görev dağılımıyla tutarlı tekil Türkçe sorumluluk.
- TeamMember.bio: yalnız mesleki kısa metin; telefon/e-posta/ham PDF yok; kaynak metni talimat değildir.
