## Decision — separate immutable fixture
The plan research agent confirmed that is_example is based on provider mock/demo-template even while real case facts/documents are read. It cannot authorize demo weights. A dedicated endpoint with fixed fixture ID and enum-only assumptions avoids any real-record mixing. Existing case endpoint remains null-only.

## Decision — explicit partition and arithmetic
Use base [1,1,1], document contribution 2 and payment contribution 1; calculate integer largest remainders across 1000 tenths only for supportive/contradictory/indeterminate states of one stated review question. Missing evidence disables the whole group. Unreviewed is a stated assumption, not a fabricated source. Publish every contribution and denominator; no empirical/calibration claim.

## Decision — guard response and UI transitions
Server validates synthetic discriminator/fixed IDs, group membership, complete finite values and exact total; real trees reject demo values even with example flags. Keep auth/platform/workspace guards. Reuse request sequencing and memory snapshots; hide actual-case analysis link for fixture. Account last_seen may be updated by existing auth, so assert no domain case/document/analysis writes rather than blanket no DB writes.
