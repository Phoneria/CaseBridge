# Clients (Müvekkiller) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a per-firm `clients` table, link every client party of a (non-precedent) case to a client, and add a client list screen, a client detail screen and a client picker in the case party form.

**Architecture:**
- **Data model.** New `clients` table. `case_parties` gains a nullable `client_id`. A party marked `is_client` on a non-precedent case always has a `client_id`, and its `name` is a copy of the client's name. `cases.client_name` stays derived from the client parties, so every existing reader (case list, search, reports, precedents, courtroom, AI context, handover) keeps working unchanged.
- **Linking.** `resolve_party_clients()` in `client_service.py` runs whenever parties are written:
  - a party sent with a `client_id` is checked against the firm and takes the client's name;
  - a client party sent without one is matched by normalized name, or a new client is created for it;
  - a non-client party never carries a `client_id`.
- **Migration.** One Alembic migration creates the table and links the existing client parties of each firm. Parties are grouped by `client_name_key`.
- **API.** New `/clients` router: list with search and counts; create; detail with stats and cases; update, where a rename rewrites the linked party names and `client_name`; delete (admin only, refused while the client has cases). The cases API gains `client_id` on parties and a `client_id` filter.
- **Frontend.**
  - `ClientPicker` combobox inside `PartiesFields`.
  - `/muvekkiller` list page (`ClientListView`, `ClientFormModal`).
  - `/muvekkiller/[id]` detail page (`ClientDetailView`).
  - A "Müvekkiller" sidebar item.
  - Prefill of the new-case form from `?muvekkil=<id>`.
  - Client names on the case page link to the client page.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic (`batch_alter_table`), pydantic v2, pytest; Next.js 14 app router, React 18, Tailwind, Vitest + Testing Library + user-event; Playwright.

**Spec:** `docs/superpowers/specs/2026-11-16-clients-design.md`

```python
"""The matching key of a client's name (clients design, "Ad normalleştirme")."""


def client_name_key(name: str) -> str:
    """Whitespace runs collapsed and trimmed, then Turkish lower case:
    "ACME  Ltd." and " acme ltd." both give "acme ltd.", "IŞIK" gives "ışık"."""
    collapsed = " ".join(name.split())
    return collapsed.replace("I", "ı").replace("İ", "i").lower()
```

`backend/alembic/versions/c8f2a4e6b0d1_add_clients.py`:

```python
"""clients table; every client party of a non-precedent case is linked to a client

Revision ID: c8f2a4e6b0d1
Revises: b9d3e7f1a520
Create Date: 2026-11-16 12:00:00

Client parties of the same firm whose names normalize to the same key share
one client. Its name is the most frequent spelling in the group (a tie goes to
the earliest party's). Linked parties take that name, and cases whose client
party names changed get client_name re-derived (names joined with ", " in
sort order, cut to 255 characters, as app.services.case_parties does).
"""
import uuid
from collections import Counter
from datetime import datetime, timezone
from typing import Sequence, Union

import sqlalchemy as sa
from alembic import op

revision: str = "c8f2a4e6b0d1"
down_revision: Union[str, Sequence[str], None] = "b9d3e7f1a520"
branch_labels: Union[str, Sequence[str], None] = None
depends_on: Union[str, Sequence[str], None] = None

FK_NAME = "fk_case_parties_client_id_clients"
MAX_JOINED_LENGTH = 255


def _name_key(name: str) -> str:
    # Copy of app.services.client_names.client_name_key: a migration must not change with app code.
    collapsed = " ".join(name.split())
    return collapsed.replace("I", "ı").replace("İ", "i").lower()


def upgrade() -> None:
    op.create_table(
        "clients",
        sa.Column("id", sa.String(36), primary_key=True),
        sa.Column("law_firm_id", sa.String(36), sa.ForeignKey("law_firms.id"), nullable=False),
        sa.Column("name", sa.String(255), nullable=False),
        sa.Column("name_key", sa.String(255), nullable=False),
        sa.Column("client_type", sa.String(20), nullable=False, server_default="person"),
        sa.Column("phone", sa.String(50), nullable=True),
        sa.Column("email", sa.String(255), nullable=True),
        sa.Column("address", sa.Text(), nullable=True),
        sa.Column("notes", sa.Text(), nullable=True),
        sa.Column("created_by", sa.String(36), sa.ForeignKey("users.id"), nullable=True),
        sa.Column("created_at", sa.DateTime(), nullable=False),
        sa.Column("updated_at", sa.DateTime(), nullable=False),
    )
    op.create_index("ix_clients_law_firm_id", "clients", ["law_firm_id"])
    op.create_index("ix_clients_law_firm_id_name_key", "clients", ["law_firm_id", "name_key"])
    with op.batch_alter_table("case_parties") as batch:
        batch.add_column(sa.Column("client_id", sa.String(36), nullable=True))
        batch.create_foreign_key(FK_NAME, "clients", ["client_id"], ["id"])
        batch.create_index("ix_case_parties_client_id", ["client_id"])
    _link_existing_parties(op.get_bind())


def _link_existing_parties(conn) -> None:
    rows = conn.execute(
        sa.text(
            "SELECT p.id, p.case_id, p.law_firm_id, p.name, p.created_at FROM case_parties p "
            "JOIN cases c ON c.id = p.case_id "
            "WHERE p.is_client = :yes AND c.is_precedent = :no ORDER BY p.created_at, p.id"
        ),
        {"yes": True, "no": False},
    ).all()
    groups: dict[tuple[str, str], list] = {}
    for row in rows:
        groups.setdefault((row.law_firm_id, _name_key(row.name)), []).append(row)

    now = datetime.now(timezone.utc).replace(tzinfo=None)
    renamed_cases: set[str] = set()
    for (law_firm_id, key), members in groups.items():
        counts = Counter(member.name for member in members)
        top = max(counts.values())
        name = next(member.name for member in members if counts[member.name] == top)
        client_id = str(uuid.uuid4())
        created_at = members[0].created_at or now
        conn.execute(
            sa.text(
                "INSERT INTO clients (id, law_firm_id, name, name_key, client_type, created_at, updated_at) "
                "VALUES (:id, :firm, :name, :key, 'person', :created, :created)"
            ),
            {"id": client_id, "firm": law_firm_id, "name": name, "key": key, "created": created_at},
        )
        for member in members:
            conn.execute(
                sa.text("UPDATE case_parties SET client_id = :client, name = :name WHERE id = :id"),
                {"client": client_id, "name": name, "id": member.id},
            )
            if member.name != name:
                renamed_cases.add(member.case_id)

    for case_id in sorted(renamed_cases):
        names = conn.execute(
            sa.text("SELECT name FROM case_parties WHERE case_id = :case AND is_client = :yes ORDER BY sort_order, id"),
            {"case": case_id, "yes": True},
        ).scalars().all()
        conn.execute(
            sa.text("UPDATE cases SET client_name = :name WHERE id = :case"),
            {"name": ", ".join(names)[:MAX_JOINED_LENGTH], "case": case_id},
        )


def downgrade() -> None:
    # Dropping the column also drops its foreign key: PostgreSQL drops it
    # with the column, and SQLite's batch copy leaves out constraints on
    # columns that no longer exist. Party names stay, so nothing is lost.
    with op.batch_alter_table("case_parties") as batch:
        batch.drop_index("ix_case_parties_client_id")
        batch.drop_column("client_id")
    op.drop_index("ix_clients_law_firm_id_name_key", table_name="clients")
    op.drop_index("ix_clients_law_firm_id", table_name="clients")
    op.drop_table("clients")
```

```python
"""A firm's clients and the link between case client parties and them.

Every write of a non-precedent case's parties goes through
resolve_party_clients(): a client party ends up with the client_id of one of
the firm's clients and with that client's name; a non-client party never has
a client_id.
"""
from dataclasses import replace
from typing import Optional, Sequence

from sqlalchemy.orm import Session

from app.models.client import Client, ClientType
from app.services.case_parties import InvalidPartiesError, PartyData
from app.services.client_names import client_name_key

UNKNOWN_CLIENT = "Seçilen müvekkil bulunamadı."


class UnknownClientError(InvalidPartiesError):
    """A party names a client that is not one of the firm's (HTTP 422 like every party rule)."""


def find_or_create_client(db: Session, law_firm_id: str, name: str, created_by: Optional[str] = None) -> Client:
    """The firm's client with this normalized name (the oldest when several
    share it), or a new person client with only the name filled in."""
    key = client_name_key(name)
    client = (
        db.query(Client)
        .filter(Client.law_firm_id == law_firm_id, Client.name_key == key)
        .order_by(Client.created_at, Client.id)
        .first()
    )
    if client is None:
        client = Client(
            law_firm_id=law_firm_id,
            name=" ".join(name.split()),
            name_key=key,
            client_type=ClientType.PERSON.value,
            created_by=created_by,
        )
        db.add(client)
        db.flush()
    return client


def resolve_party_clients(
    db: Session, law_firm_id: str, parties: Sequence[PartyData], created_by: Optional[str] = None
) -> list[PartyData]:
    """Raises UnknownClientError when a party names a client the firm does not have."""
    resolved: list[PartyData] = []
    for party in parties:
        if not party.is_client:
            resolved.append(replace(party, client_id=None))
            continue
        if party.client_id is not None:
            client = (
                db.query(Client)
                .filter(Client.id == party.client_id, Client.law_firm_id == law_firm_id)
                .first()
            )
            if client is None:
                raise UnknownClientError(UNKNOWN_CLIENT)
        else:
            client = find_or_create_client(db, law_firm_id, party.name, created_by)
        resolved.append(replace(party, name=client.name, client_id=client.id))
    return resolved
```

```python
class ClientService:
    def __init__(self, db: Session):
        self.db = db

    def list_clients(
        self, law_firm_id: str, q: Optional[str] = None, limit: int = 50, offset: int = 0
    ) -> list[tuple[Client, int, int]]:
        """(client, case_count, open_case_count) rows ordered by name. Counts skip precedents."""
        linked_case = and_(Case.id == CaseParty.case_id, Case.is_precedent.is_(False))
        case_count = func.count(distinct(Case.id))
        open_count = func.count(distinct(sql_case((case_is_active(), Case.id), else_=None)))
        query = (
            self.db.query(Client, case_count, open_count)
            .outerjoin(CaseParty, CaseParty.client_id == Client.id)
            .outerjoin(Case, linked_case)
            .filter(Client.law_firm_id == law_firm_id)
        )
        if q and q.strip():
            raw = f"%{q.strip()}%"
            query = query.filter(
                or_(
                    Client.name_key.like(f"%{client_name_key(q)}%"),
                    Client.phone.ilike(raw),
                    Client.email.ilike(raw),
                )
            )
        rows = query.group_by(Client.id).order_by(Client.name_key, Client.id).offset(offset).limit(limit).all()
        return [(client, int(total or 0), int(open_ or 0)) for client, total, open_ in rows]

    def get(self, client_id: str, law_firm_id: str) -> Optional[Client]:
        return self.db.query(Client).filter(Client.id == client_id, Client.law_firm_id == law_firm_id).first()

    def create(self, law_firm_id: str, payload: ClientCreate, created_by: Optional[str]) -> Client:
        name = " ".join(payload.name.split())
        client = Client(
            law_firm_id=law_firm_id,
            name=name,
            name_key=client_name_key(name),
            client_type=payload.client_type.value,
            phone=payload.phone,
            email=str(payload.email) if payload.email else None,
            address=payload.address,
            notes=payload.notes,
            created_by=created_by,
        )
        self.db.add(client)
        self.db.commit()
        self.db.refresh(client)
        return client

    def update(self, client: Client, payload: ClientUpdate) -> Client:
        fields = payload.model_fields_set
        renamed = False
        if "name" in fields:
            name = " ".join(payload.name.split())
            renamed = name != client.name
            client.name = name
            client.name_key = client_name_key(name)
        if "client_type" in fields:
            client.client_type = payload.client_type.value
        if "email" in fields:
            client.email = str(payload.email) if payload.email else None
        for field in ("phone", "address", "notes"):
            if field in fields:
                setattr(client, field, getattr(payload, field))
        if renamed:
            self._rename_linked_parties(client)
        self.db.commit()
        self.db.refresh(client)
        return client

    def _rename_linked_parties(self, client: Client) -> None:
        """Linked party names follow the client's name; every touched case
        (archived ones too: client_name is a derived copy) gets client_name
        re-derived from its client parties."""
        parties = self.db.query(CaseParty).filter(CaseParty.client_id == client.id).all()
        for party in parties:
            party.name = client.name
        self.db.flush()
        case_ids = {party.case_id for party in parties}
        if not case_ids:
            return
        for case in self.db.query(Case).filter(Case.id.in_(case_ids)).all():
            data = [PartyData(p.name, p.role, p.is_client, p.counsel_name) for p in case.parties]
            case.client_name = derive_client_name(data) or case.client_name

    def delete(self, client: Client) -> None:
        if self.db.query(CaseParty.id).filter(CaseParty.client_id == client.id).first() is not None:
            raise ClientHasCasesError(CLIENT_HAS_CASES)
        self.db.delete(client)
        self.db.commit()

    def cases_of(self, client: Client) -> list[Case]:
        """Open cases first, then by next hearing (none last), then newest opening date."""
        cases = (
            self.db.query(Case)
            .filter(
                Case.law_firm_id == client.law_firm_id,
                Case.is_precedent.is_(False),
                Case.parties.any(CaseParty.client_id == client.id),
            )
            .all()
        )

        def order(case: Case):
            hearing = case.next_hearing_date
            opened = case.opening_date or date.min
            return (0 if _is_open(case) else 1, hearing is None, hearing or date.min, -opened.toordinal())

        return sorted(cases, key=order)

    @staticmethod
    def stats_of(cases: list[Case]) -> dict:
        return {
            "total": len(cases),
            "open": sum(1 for c in cases if _is_open(c)),
            "closed": sum(1 for c in cases if c.status == CaseStatus.KAPALI),
            "archived": sum(1 for c in cases if c.is_archived),
            "won": sum(1 for c in cases if c.outcome == CaseOutcome.WON),
            "lost": sum(1 for c in cases if c.outcome == CaseOutcome.LOST),
            "settled": sum(1 for c in cases if c.outcome == CaseOutcome.SETTLED),
            "total_case_value": float(sum(c.case_value or 0 for c in cases)),
        }
```

```ts
export interface ClientListFilters {
  q?: string;
  limit?: number;
  offset?: number;

export async function listClients(filters: ClientListFilters = {}): Promise<ClientListItem[]> {
  const params = new URLSearchParams();
  if (filters.q?.trim()) params.set("q", filters.q.trim());
  if (filters.limit) params.set("limit", String(filters.limit));
  if (filters.offset) params.set("offset", String(filters.offset));
  const query = params.toString();
  return request(`/clients${query ? `?${query}` : ""}`);
}
```

```tsx
"use client";

import Link from "next/link";
import { useEffect, useId, useRef, useState, type KeyboardEvent } from "react";

import { INPUT_CLASS } from "@/components/case-form/Field";
import { createClient, listClients } from "@/lib/api";
import { CLIENT_TYPE_LABELS } from "@/lib/clients";
import { userMessage } from "@/lib/userMessages";
import type { ClientListItem } from "@/types";

export const SEARCH_DELAY_MS = 250;

interface Props {
  inputId: string;
  /** The typed text, or the chosen client's name. */
  query: string;
  clientId: string | null;
  maxLength: number;
  invalid?: boolean;
  describedBy?: string;
  onQueryChange: (text: string) => void;
  onSelect: (client: { id: string; name: string }) => void;
  onClear: () => void;
}

type Option = { kind: "client"; client: ClientListItem } | { kind: "new" };

/** Name field of a client party: search the firm's clients, or add the typed name as a new client. */
export function ClientPicker({ inputId, query, clientId, maxLength, invalid, describedBy, onQueryChange, onSelect, onClear }: Props) {
  const listId = useId();
  const [results, setResults] = useState<ClientListItem[]>([]);
  // Open from the start: a name the AI filled in shows its suggestions right away.
  const [open, setOpen] = useState(true);
  const [active, setActive] = useState(-1);
  const [creating, setCreating] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const requestId = useRef(0);
  const inFlight = useRef(false);
  const trimmed = query.trim();

  useEffect(() => {
    const id = ++requestId.current;
    if (clientId || !trimmed) {
      setResults([]);
      return;
    }
    const timer = setTimeout(() => {
      listClients({ q: trimmed, limit: 10 })
        .then((items) => requestId.current === id && setResults(items))
        .catch(() => requestId.current === id && setResults([]));
    }, SEARCH_DELAY_MS);
    return () => clearTimeout(timer);
  }, [trimmed, clientId]);

  if (clientId) {
    return (
      <div className="flex min-h-[38px] items-center justify-between gap-2 rounded-lg border border-accent-200 bg-accent-50 px-3 py-1.5">
        <Link href={`/muvekkiller/${clientId}`} className="truncate text-sm font-medium text-accent-700 hover:underline">
          {query}
        </Link>
        <button
          type="button"
          aria-label="Müvekkili değiştir"
          onClick={() => {
            setOpen(true);
            onClear();
          }}
          className="shrink-0 text-xs font-semibold text-navy-600 hover:text-accent-700"
        >
          Değiştir
        </button>
      </div>
    );
  }

  const options: Option[] = [
    ...results.map((client) => ({ kind: "client" as const, client })),
    ...(trimmed ? [{ kind: "new" as const }] : []),
  ];
  const expanded = open && options.length > 0;

  async function addNew() {
    if (inFlight.current || !trimmed) return;
    inFlight.current = true;
    setCreating(true);
    setError(null);
    try {
      const client = await createClient({ name: trimmed, client_type: "person", phone: null, email: null, address: null, notes: null });
      onSelect({ id: client.id, name: client.name });
    } catch (err) {
      setError(userMessage(err, "Müvekkil eklenemedi."));
    } finally {
      inFlight.current = false;
      setCreating(false);
    }
  }

  function choose(index: number) {
    const option = options[index];
    if (!option) return;
    if (option.kind === "new") void addNew();
    else onSelect({ id: option.client.id, name: option.client.name });
  }

  function onKeyDown(event: KeyboardEvent<HTMLInputElement>) {
    if (event.key === "ArrowDown") {
      event.preventDefault();
      setOpen(true);
      setActive((index) => Math.min(index + 1, options.length - 1));
    } else if (event.key === "ArrowUp") {
      event.preventDefault();
      setActive((index) => Math.max(index - 1, 0));
    } else if (event.key === "Enter" && expanded) {
      // Never submit the case form from the suggestion list.
      event.preventDefault();
      if (active >= 0) choose(active);
    } else if (event.key === "Escape") {
      setOpen(false);
      setActive(-1);
    }
  }

  return (
    <div className="relative">
      <input
        id={inputId}
        role="combobox"
        aria-expanded={expanded}
        aria-controls={listId}
        aria-autocomplete="list"
        aria-activedescendant={expanded && active >= 0 ? `${listId}-${active}` : undefined}
        aria-invalid={Boolean(invalid)}
        aria-required="true"
        aria-describedby={describedBy}
        autoComplete="off"
        maxLength={maxLength}
        className={INPUT_CLASS}
        value={query}
        onChange={(event) => {
          onQueryChange(event.target.value);
          setOpen(true);
          setActive(-1);
        }}
        onFocus={() => setOpen(true)}
        onBlur={() => setOpen(false)}
        onKeyDown={onKeyDown}
      />
      {expanded && (
        <ul
          id={listId}
          role="listbox"
          aria-label="Müvekkil önerileri"
          className="absolute z-20 mt-1 max-h-64 w-full overflow-auto rounded-xl border border-surface-border bg-white py-1 shadow-card"
        >
          {options.map((option, index) => (
            <li
              key={option.kind === "client" ? option.client.id : "new"}
              id={`${listId}-${index}`}
              role="option"
              aria-selected={index === active}
              // Keep the input focused so the click lands before the list closes on blur.
              onMouseDown={(event) => event.preventDefault()}
              onClick={() => choose(index)}
              className={`cursor-pointer px-3 py-2 text-sm ${index === active ? "bg-accent-50" : "hover:bg-surface-muted"}`}
            >
              {option.kind === "client" ? (
                <>
```

```tsx
"use client";

import { useRef, useState } from "react";

import { INPUT_CLASS } from "@/components/case-form/Field";
import { ModalFrame } from "@/components/ModalFrame";
import { createClient, updateClient } from "@/lib/api";
import { CLIENT_TYPE_LABELS, isValidEmail } from "@/lib/clients";
import { userMessage } from "@/lib/userMessages";
import type { Client, ClientPayload, ClientType } from "@/types";

interface Props {
  title: string;
  /** The client being edited; a new client when missing. */
  initial?: Client | null;
  onSaved: (client: Client) => void;
  onClose: () => void;
}

const LABEL = "mb-1 block text-xs font-medium text-navy-600";

/** Create or edit a client: name, type and contact details. */
export function ClientFormModal({ title, initial, onSaved, onClose }: Props) {
  const [name, setName] = useState(initial?.name ?? "");
  const [clientType, setClientType] = useState<ClientType>(initial?.client_type ?? "person");
  const [phone, setPhone] = useState(initial?.phone ?? "");
  const [email, setEmail] = useState(initial?.email ?? "");
  const [address, setAddress] = useState(initial?.address ?? "");
  const [notes, setNotes] = useState(initial?.notes ?? "");
  const [errors, setErrors] = useState<{ name?: string; email?: string }>({});
  const [error, setError] = useState<string | null>(null);
  const [saving, setSaving] = useState(false);
  const inFlight = useRef(false);

  async function save() {
    if (inFlight.current) return;
    const nextErrors = {
      name: name.trim() ? undefined : "Ad gerekli.",
      email: email.trim() && !isValidEmail(email) ? "Geçerli bir e-posta girin." : undefined,
    };
    setErrors(nextErrors);
    if (nextErrors.name || nextErrors.email) return;
    const blank = (value: string) => value.trim() || null;
    const payload: ClientPayload = {
      name: name.trim(),
      client_type: clientType,
      phone: blank(phone),
      email: blank(email),
      address: blank(address),
      notes: blank(notes),
    };
    inFlight.current = true;
    setSaving(true);
    setError(null);
    try {
      onSaved(initial ? await updateClient(initial.id, payload) : await createClient(payload));
    } catch (err) {
      setError(userMessage(err, "Müvekkil kaydedilemedi."));
    } finally {
      inFlight.current = false;
      setSaving(false);
    }
  }

  return (
    <ModalFrame title={title} onClose={onClose} busy={saving}>
      <div className="space-y-3">
        <div>
          <label htmlFor="client-name" className={LABEL}>
            Ad / unvan <span aria-hidden="true" className="text-red-500">*</span>
          </label>
          <input id="client-name" data-autofocus className={INPUT_CLASS} maxLength={255} value={name}
            aria-invalid={Boolean(errors.name)} aria-describedby={errors.name ? "client-name-hata" : undefined}
            onChange={(e) => setName(e.target.value)} />
          {errors.name && <p id="client-name-hata" className="mt-1 text-xs text-red-600">{errors.name}</p>}
        </div>
        <div>
          <label htmlFor="client-type" className={LABEL}>Tür</label>
          <select id="client-type" className={INPUT_CLASS} value={clientType} onChange={(e) => setClientType(e.target.value as ClientType)}>
            {(Object.keys(CLIENT_TYPE_LABELS) as ClientType[]).map((type) => (
              <option key={type} value={type}>{CLIENT_TYPE_LABELS[type]}</option>
            ))}
          </select>
        </div>
        <div className="grid grid-cols-1 gap-3 sm:grid-cols-2">
          <div>
            <label htmlFor="client-phone" className={LABEL}>Telefon</label>
            <input id="client-phone" type="tel" className={INPUT_CLASS} maxLength={50} value={phone} onChange={(e) => setPhone(e.target.value)} />
          </div>
          <div>
            <label htmlFor="client-email" className={LABEL}>E-posta</label>
            <input id="client-email" type="email" className={INPUT_CLASS} maxLength={255} value={email}
              aria-invalid={Boolean(errors.email)} aria-describedby={errors.email ? "client-email-hata" : undefined}
              onChange={(e) => setEmail(e.target.value)} />
            {errors.email && <p id="client-email-hata" className="mt-1 text-xs text-red-600">{errors.email}</p>}
          </div>
        </div>
        <div>
          <label htmlFor="client-address" className={LABEL}>Adres</label>
          <textarea id="client-address" rows={2} className={INPUT_CLASS} maxLength={4000} value={address} onChange={(e) => setAddress(e.target.value)} />
        </div>
        <div>
          <label htmlFor="client-notes" className={LABEL}>Not</label>
          <textarea id="client-notes" rows={3} className={INPUT_CLASS} maxLength={4000} value={notes} onChange={(e) => setNotes(e.target.value)} />
        </div>
        {error && <p role="alert" className="text-sm text-red-600">{error}</p>}
        <div className="flex justify-end gap-2 pt-1">
          <button type="button" onClick={onClose}
            className="rounded-xl border border-surface-border px-4 py-2 text-sm font-medium text-navy-700 hover:bg-surface-muted">
            Vazgeç
          </button>
          <button type="button" aria-disabled={saving} onClick={save}
            className="rounded-xl bg-accent-600 px-4 py-2 text-sm font-medium text-white hover:bg-accent-700 aria-disabled:opacity-50">
            Kaydet
          </button>
        </div>
      </div>
    </ModalFrame>
  );
}
```

```tsx
"use client";

import Link from "next/link";
import { useRouter } from "next/navigation";
import { useEffect, useRef, useState } from "react";

import { ClientFormModal } from "@/components/ClientFormModal";
import { EmptyState } from "@/components/EmptyState";
import { ErrorState } from "@/components/ErrorState";
import { LoadingState } from "@/components/LoadingState";
import { listClients } from "@/lib/api";
import { CLIENT_TYPE_LABELS } from "@/lib/clients";
import { userMessage } from "@/lib/userMessages";
import type { ClientListItem } from "@/types";

export const CLIENT_PAGE_SIZE = 50;
const SEARCH_DELAY_MS = 300;
const PAGER = "rounded-xl border border-surface-border px-3 py-1.5 text-sm text-navy-700 hover:bg-surface-muted aria-disabled:opacity-40";

export function ClientListView() {
  const router = useRouter();
  const [input, setInput] = useState("");
  const [q, setQ] = useState("");
  const [offset, setOffset] = useState(0);
  const [items, setItems] = useState<ClientListItem[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);
  const [creating, setCreating] = useState(false);
  const requestId = useRef(0);

  useEffect(() => {
    // Only a changed search resets the page (the first render must not undo a quick "Sonraki").
    const next = input.trim();
    if (next === q) return;
    const timer = setTimeout(() => {
      setQ(next);
      setOffset(0);
    }, SEARCH_DELAY_MS);
    return () => clearTimeout(timer);
  }, [input, q]);

  useEffect(() => {
    const id = ++requestId.current;
    setLoading(true);
    setError(null);
    listClients({ q, limit: CLIENT_PAGE_SIZE, offset })
      .then((rows) => requestId.current === id && setItems(rows))
      .catch((err) => requestId.current === id && setError(userMessage(err, "Müvekkiller yüklenemedi.")))
      .finally(() => requestId.current === id && setLoading(false));
  }, [q, offset]);

  const hasNext = items.length === CLIENT_PAGE_SIZE;

  return (
    <div className="space-y-5">
      <header className="flex flex-wrap items-center justify-between gap-3">
        <h1 className="text-2xl font-semibold text-navy-900">Müvekkiller</h1>
        <button type="button" onClick={() => setCreating(true)}
          className="rounded-xl bg-accent-600 px-4 py-2 text-sm font-medium text-white hover:bg-accent-700">
          Yeni müvekkil
        </button>
      </header>

      <input type="search" aria-label="Müvekkil ara" placeholder="Ad, telefon veya e-posta" value={input}
        onChange={(e) => setInput(e.target.value)}
        className="w-full max-w-md rounded-xl border border-surface-border bg-white px-3 py-2 text-sm text-navy-800 outline-none focus:border-accent-400" />

      {loading ? (
        <LoadingState />
      ) : error ? (
        <ErrorState message={error} />
      ) : items.length === 0 ? (
        q ? <EmptyState message="Aramanızla eşleşen müvekkil yok." />
          : <EmptyState message="Henüz müvekkil yok." hint="Yeni müvekkil ekleyin veya bir dava açın." />
      ) : (
        <div className="overflow-x-auto rounded-2xl border border-surface-border bg-white shadow-card">
          <table className="w-full text-left text-sm">
            <thead className="bg-surface-muted text-xs uppercase text-navy-500">
              <tr>
                <th className="px-4 py-3">Ad</th>
                <th className="px-4 py-3">Tür</th>
                <th className="px-4 py-3">Telefon</th>
                <th className="px-4 py-3">E-posta</th>
                <th className="px-4 py-3 text-right">Dava</th>
                <th className="px-4 py-3 text-right">Açık</th>
              </tr>
            </thead>
            <tbody className="divide-y divide-surface-border">
              {items.map((item) => (
                <tr key={item.id} className="cursor-pointer hover:bg-surface-muted" onClick={() => router.push(`/muvekkiller/${item.id}`)}>
                  <td className="px-4 py-3">
                    <Link href={`/muvekkiller/${item.id}`} onClick={(e) => e.stopPropagation()} className="font-medium text-navy-800 hover:text-accent-700">
                      {item.name}
                    </Link>
                  </td>
                  <td className="px-4 py-3 text-navy-600">{CLIENT_TYPE_LABELS[item.client_type]}</td>
```
